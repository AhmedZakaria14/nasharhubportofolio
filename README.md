# NasharHub — Digital Growth Portfolio

تجربة بورتفوليو عربية أولاً لشركة **NasharHub**، تعرض دراسات تصميم المواقع، أدلة الظهور في البحث، ولوحات أداء إعلانات Google ضمن هوية تحريرية متجاوبة.

## التشغيل المحلي

يتطلب المشروع Node.js 22 أو أحدث وpnpm.

```bash
pnpm install
pnpm dev
```

لإنشاء نسخة إنتاجية، استخدم الأمر التالي:

```bash
pnpm build
```

## البنية التقنية

| المجال | التقنية المستخدمة |
| --- | --- |
| الواجهة | React 19 + TypeScript |
| التنسيق | Tailwind CSS 4 + CSS مخصص |
| الحركة | Framer Motion |
| الاتجاه | RTL وأولوية كاملة للغة العربية |

## ملاحظات الأصول

تُضمَّن حالياً جميع الصور المستخدمة في واجهة البورتفوليو، وعددها **91 أصلاً بصرياً**، داخل `client/public/portfolio`. لذلك تعمل دراسات الحالات ولوحات SEO وGoogle Ads بعد نشر المستودع مباشرة على Vercel دون الاعتماد على روابط تخزين خارجية.

## النشر على Vercel

يحتوي المشروع على ملف `vercel.json` يحدّد النشر كتطبيق Vite ثابت، ومجلد المخرج `dist`، وإعادة كتابة لمسارات الواجهة إلى `index.html`. عند استيراد المستودع في Vercel، اترك الإعدادات المكتشفة كما هي أو استخدم **Build Command**: `pnpm build` و**Output Directory**: `dist`.
